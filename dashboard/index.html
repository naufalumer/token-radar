The model — radar-2, calibrated on the snapshot itself

implied = TVL × category multiple × growth × maturity × chain reach

  • Category multiple — median market-cap / TVL of the live-token protocols in the same category (3+ peers), else the whole-market median; clamped to 0.05–1.00.
  • Growth — 1 + clamp(7-day TVL change, −50%, +100%) × 0.6.
  • Maturity — 0.70 + min(age, 1095 days) / 1095 × 0.30; unknown age counts as 365 days.
  • Chain reach — 1 + min(chains − 1, 5) × 0.02.

No protocol name is special-cased. The calibration table below is recomputed from whatever snapshot the program is handed, so the radar keeps working on protocols that do not exist yet.
